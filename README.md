Entry for the make.fun competition
[Pigeon Pitch, One Line](https://make.fun/bounty/u-donrulezz-pigeon-pitch-one-line-af06c6cf)
(`u-donrulezz-pigeon-pitch-one-line-af06c6cf`).

The program (`main.py`, Python 3.13) writes one line — at most 200 characters —
the elevator pitch a city pigeon gives investors for its startup,
to `/output/entry.txt`:

> Investors, I run StatueBnB — 10,000 pigeons, zero rent, every bronze hero in town already our premium perch. We just need a seed round. Literally. Seed.

The joke: the pigeons already occupy every statue in the city rent-free, so the
"startup" just monetises the perches — and the seed round is literal birdseed.

## Run

```sh
python3 main.py   # writes /output/entry.txt
```
